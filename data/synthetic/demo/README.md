# Synthetic demo dataset

> **SYNTHETIC. Invented for testing mechanics only.** No real place, person, service or
> organisation is described. Every number is a placeholder and must **never** be read as a
> research parameter (populations, speeds, capacities, waiting times, severities).

Generated by [`scripts/generate_demo_data.py`](../../../scripts/generate_demo_data.py)
(standard library only, no randomness, so it is reproducible). Processing note:
[DP-001](../../../docs/data-processing/DP-001-synthetic-demo-dataset.md).
Turned into the demo data packages by `scripts/build_demo_packages.py` (DP-002, imported by
`make seed`), and read directly from these files by
tests (`core/tests/test_demo_dataset.py`).

## Study area

Two fictional municipalities on a 2 km grid, in **EPSG:2100** (GGRS87 / Greek Grid). The grid
origin is deliberately placed in open sea (about 35° N, 20° E), so a basemap shows water: no
real place is implied.

```
 y (km)
 4 ┌──────┬──────┬──────┬──────┐
   │  A4  │  A5  │  A6  │  B2  │      M-A: municipality A (study, core): A1–A6
   │  ●   │  ●   │  ● F2│  ●   │      M-B: municipality B (neighbour, buffer, OQ-28): B1, B2
 2 ├──────┼──────┼──────┼──────┤
   │  A1  │  A2  │  A3  │  B1  │      ● unit population centroid (network node N-<unit>)
   │  ●   │  ● F1│  ●   │F4 ●  │      F1–F4 facilities; F4 lies in M-B, 0.5 km past the
   │  F3  │      │      │      │      boundary at x = 6 km
 0 └──────┴──────┴──────┴──────┘
   0      2      4      6      8  x (km)
```

## Files

| File | Content |
| --- | --- |
| `demo.gpkg` | GeoPackage layers `municipalities`, `spatial_units` (polygons), `unit_centroids`, `facilities` (points). Units and facilities carry `municipality_id`, `role` (`core` or `buffer`), `quality`, `valid_from`, `valid_to` (Spec 00 §3, stable identifiers) |
| `groups.csv` | 3 population groups with placeholder definition rules. Groups may overlap (OQ-6): do not sum population across groups |
| `population.csv` | population per unit and group (placeholder head counts) |
| `services.csv` | 2 services with their service unit (`hour`, `appointment`) and a placeholder maximum acceptable waiting time (ISO 8601 duration; OQ-26 values are open) |
| `facility_services.csv` | services offered per facility with placeholder capacity inputs (places, staff, throughput) |
| `network_nodes.csv` | network nodes: unit centroids and facility locations (x, y in EPSG:2100 metres) |
| `network_edges.csv` | undirected edges, one row per edge and mode (`walk`, `car`), with length in metres, travel time in minutes and whether the edge can be closed |
| `hand_check_travel_times.csv` | expected shortest travel time from every unit centroid to every facility, per mode, for the baseline and for the reference scenario, with one shortest path |
| `scenarios/C-DEMO-REF.json` | the reference disruption scenario |
| `manifest.json` | package metadata (draft format, ADR 0013): version, CRS, study area, coverage, `DP-NNN` processing notes, SHA-256 checksum of every file |

## Network

Uniform placeholder speeds make times easy to check by hand: **walking 12 min per km**
(5 km/h), **car 2 min per km** (30 km/h). The same edges exist for both modes.

| Edge | From – to | Length | Note |
| --- | --- | --- | --- |
| E01 | A1 – A2 | 2000 m | |
| E02 | A2 – A3 | 2000 m | **closable**; closed in the reference scenario |
| E03 | A3 – F4 | 1500 m | crosses the municipal boundary |
| E04 | F4 – B1 | 500 m | |
| E05 | A5 – A6 | 2000 m | |
| E06 | A6 – B2 | 2000 m | |
| E07 | A2 – F1 | 500 m | |
| E08 | F1 – A5 | 1500 m | |
| E09 | A3 – F2 | 1500 m | |
| E10 | F2 – A6 | 500 m | |
| E11 | B1 – B2 | 2000 m | |
| E12 | A1 – F3 | 500 m | |
| E13 | A4 – A5 | 5000 m | **A4 is badly connected**: its only link is a winding road; the length attribute is authoritative, not the straight line |

### Worked examples (check by hand)

- A1 → F3, walking: E12, 0.5 km × 12 = **6 min**.
- A4 → F2, car: E13 + E05 + E10 = 5 + 2 + 0.5 = 7.5 km × 2 = **15 min**.
- A3 → F4 (cross-border), walking: E03 = 1.5 km × 12 = **18 min**.
- A1 → F2, walking, baseline: E01 + E02 + E09 = 5.5 km → **66 min**. With E02 closed:
  E01 + E07 + E08 + E05 + E10 = 6.5 km → **78 min**.

Where two paths have the same length (for example A4 → F4), the table shows one of them; the
time is what matters.

## Reference disruption scenario `C-DEMO-REF`

Facility **F1 at severity 0.5** and edge **E02 closed** for walking and car. The rationing case
is set to `uniform` only because the core model requires every disruption scenario to state one
(OQ-24); it is a placeholder. This is a test scenario, **not** one of the OQ-16 reference levels
(minor, moderate, severe), whose construction is open.

## Regenerating

```bash
python3 scripts/generate_demo_data.py
```

The output is byte-for-byte reproducible. If you change the generator, bump `PACKAGE_VERSION`,
add a changelog line, and update DP-001.
