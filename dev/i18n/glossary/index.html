    Greek–English glossary¶

    The platform is used in Greek and English. These are the terms to use in the user interface (frontend/src/i18n/el.json, en.json), in documentation written in Greek and in the papers' Greek summaries. Decided terms were chosen by the maintainer; in use terms are what the UI uses today and change only by editing this file first; proposed terms were added with the Greek documentation site and wait for the maintainer's approval.

    When a term is missing, add it here in the same pull request that first uses it. Keep a concept's term the same everywhere; do not translate one concept two ways.

    Texts from the server¶

    Errors and messages from the backend and core (for example "run not found", reference problems, "recorded only" lines) come from one catalogue of English templates with stable codes (core/.../model/messages.py, backend/.../messages.py, exported to docs/schemas/messages.json by make schemas). The UI translates them with the keys server.<code> in en.json and el.json; a frontend test fails when a code has no translation. Package validation messages (Admin → package preview) are the one exception: they quote file, table and column names for the administrator and stay in English, under a translated note saying so.
