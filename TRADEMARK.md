# Trademark policy (draft)

> **Status: DRAFT. This policy needs legal review before it is relied on.** It does not claim that "SolidarityNode" is a registered trademark.

The SolidarityNode **code** is licensed under the AGPL-3.0. The AGPL does not grant rights to the project **name** or logos. This short policy explains how the name may be used, so that people can tell the official project apart from modified versions.

## You may, without asking

- Refer to the project by name in articles, talks, research papers and teaching ("built with SolidarityNode", "a fork of SolidarityNode").
- Use the name for unmodified copies of the software.
- State truthfully that your software is based on or compatible with SolidarityNode.

## Please ask first

- Using the name, or a confusingly similar one, for a modified version, a hosted service, a product or a company.
- Using the name in a domain name or social media handle.
- Implying that a deployment or analysis is endorsed, validated or operated by the SolidarityNode project.

## Modified versions

If you distribute or host a modified version (as the AGPL allows), give it a different name and say it is based on SolidarityNode. This protects users: results from a modified model must not be mistaken for results of the reviewed method.

## Contact

Write to solidarityNode@gmail.com to ask for permission, or open an issue or discussion in the repository.
