# Ρόλοι { #roles }

> Περιγράφει την έκδοση **0.1.0** της πλατφόρμας.

| Ρόλος | Στα αγγλικά | Μπορεί να |
| --- | --- | --- |
| **Θεατής** | viewer | Βλέπει τα κοινόχρηστα σενάρια και τις εκτελέσεις τους: αποτελέσματα, χάρτη, πίνακα, εξαγωγές. Δεν μπορεί να δημιουργήσει, να αλλάξει ή να εκτελέσει σενάρια. |
| **Αναλυτής** | analyst | Ό,τι και ο θεατής, και επιπλέον να δημιουργεί, να αλλάζει, να εκτελεί, να αντιγράφει και να μοιράζεται τα δικά του σενάρια, και να εκτελεί τη βάση. |
| **Διαχειριστής** | administrator | Ό,τι και ο αναλυτής, σε κάθε σενάριο (και στα ιδιωτικά σενάρια άλλων χρηστών), και επιπλέον να διαχειρίζεται χρήστες, να εισάγει πακέτα δεδομένων και να επιλέγει την ενεργή έκδοση δεδομένων. |
| **Κεντρικός φορέας δεδομένων** (εκτός της εγκατάστασής σας) | hub | Φτιάχνει και δημοσιεύει πακέτα δεδομένων· δέχεται διορθώσεις στα δεδομένα. Προγραμματίζεται για την έκδοση v0.2 ([πορεία ανάπτυξης](../roadmap.md)). |

Τα **ιδιωτικά** σενάρια τα βλέπουν ο κάτοχός τους και οι διαχειριστές· τα **κοινόχρηστα** τα βλέπουν όλοι οι χρήστες. Μια εκτέλεση έχει την ίδια ορατότητα με το σενάριό της: για τους άλλους χρήστες, η εκτέλεση ενός ιδιωτικού σεναρίου «δεν βρέθηκε».

Ο ίδιος πίνακας, με την αιτιολόγηση, υπάρχει στις [Βασικές έννοιες](../concepts.md#who-does-what)· η απόφαση είναι το [ADR 0015](../adr/0015-authentication-and-roles.md) (στα αγγλικά).
