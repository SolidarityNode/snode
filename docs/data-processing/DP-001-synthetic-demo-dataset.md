## Purpose
A small, fully synthetic study area for automated tests and manual UAT: loading, joins,
shortest-path checks against known answers, cross-border effects and a disruption overlay. Not
used in any paper. Every value is a placeholder.

## Coordinate reference system
Output in EPSG:2100 (GGRS87 / Greek Grid), the CRS planned for the first application, so the
same tooling is exercised. The grid origin (130000, 3880000) lies in open sea (about 35° N,
20° E) so that no real place is implied. No reprojection.

## Steps
1. **Generate** all layers and tables:
   ```bash
   python3 scripts/generate_demo_data.py
   ```
   The script writes the GeoPackage with the standard-library `sqlite3` module (GeoPackage 1.4
   tables and geometry encoding), the CSV tables, the scenario JSON, the hand-check table
   (Dijkstra over the edge list, per mode, baseline and with edge E02 closed) and
   `manifest.json` with SHA-256 checksums.
2. **Manual edits:** none.

- [x] Feature counts: 2 municipalities, 8 units, 8 centroids, 4 facilities.
- [x] Geometry validity: all polygons valid (Shapely `is_valid`), each unit 4 km².
- [x] Visual check: not applicable (open sea by design).
- [x] Spot checks: worked examples in `data/synthetic/demo/README.md`; `core/tests/test_demo_dataset.py` recomputes every hand-check time from the edge list and verifies the manifest checksums.
- [x] Running the generator twice gives byte-identical files.

## Assumptions and limitations
- Uniform placeholder speeds (walking 12 min/km, car 2 min/km); the same edges for both modes.
- Unit centroids are the square centres; edge E13 is longer than the straight line between its
  nodes by design (a winding road).
- The buffer is the whole neighbouring municipality for this demo only; the buffer rule is open
  (OQ-28).
- Rationing `uniform` in the scenario is a placeholder required by the model (OQ-24).
