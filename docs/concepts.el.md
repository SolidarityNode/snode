# Πώς λειτουργεί το SolidarityNode: οι βασικές ιδέες { #how-solidaritynode-works-the-main-ideas }

Για τους υπαλλήλους των δήμων που χρησιμοποιούν την πλατφόρμα: αναλυτές, θεατές και
διαχειριστές. Δεν χρειάζονται τεχνικές γνώσεις. Οι λέξεις με **έντονα** γράμματα είναι αυτές
που βλέπετε στην οθόνη.

## Με λίγα λόγια { #the-short-version }

- Ένα **πακέτο δεδομένων** λέει *τι ισχύει*: τα επίσημα δεδομένα της περιοχής μελέτης.
- Ένα **σενάριο** ρωτά *τι θα γινόταν αν*: μια υπόθεση πάνω σε αυτά τα δεδομένα.
- Μια **εκτέλεση** υπολογίζει την απάντηση: ένα σενάριο με μία έκδοση των δεδομένων, που
  διατηρείται αμετάβλητη για πάντα.

## Πακέτο δεδομένων: τι ισχύει { #data-package-what-is-true }

Ένα πακέτο δεδομένων περιέχει τα επίσημα, κοινά δεδομένα της περιοχής μελέτης: τις χωρικές
μονάδες με τον πληθυσμό τους ανά κοινωνική ομάδα, τις δομές με τις υπηρεσίες που προσφέρουν, και
το οδικό δίκτυο.

- Το **φτιάχνει και το δημοσιεύει η κεντρική εγκατάσταση (hub)**, όπου ετοιμάζονται τα
  δεδομένα για όλους τους δήμους, από επίσημες πηγές και ανοιχτά δεδομένα, με σημείωση
  επεξεργασίας για κάθε βήμα.
- Το **εισάγει μόνο ένας διαχειριστής** της εγκατάστασης του δήμου σας (**Διαχείριση** (Admin) →
  **Πακέτα δεδομένων** (Data packages)). Οι αναλυτές και οι θεατές δεν ανεβάζουν ποτέ δεδομένα.
- Έχει **εκδόσεις**: κάθε εισαγωγή δημιουργεί νέα **έκδοση δεδομένων** (για παράδειγμα 1.0.0,
  μετά 1.1.0). Οι προηγούμενες εκδόσεις διατηρούνται, ώστε ένας διαχειριστής να μπορεί να
  ενεργοποιήσει ξανά μια παλαιότερη.
- Μία έκδοση δεδομένων είναι **ενεργή**: αυτήν χρησιμοποιούν τα νέα σενάρια και οι νέες εκτελέσεις.
- Η σελίδα **Περιοχή μελέτης** (Study area) δείχνει την ενεργή έκδοση, τις άδειες χρήσης της, και
  πόσο καλό είναι κάθε επίπεδο (επαληθευμένο από τον δήμο, ανοιχτά δεδομένα, εκτίμηση ή λείπει).

**Οι αναλυτές δεν ανεβάζουν δεδομένα.** Για να δοκιμάσετε μια αλλαγή, όπως έναν κλειστό δρόμο,
μια νέα δομή ή περισσότερο προσωπικό, γράψτε ένα **σενάριο**. Αν τα ίδια τα δεδομένα είναι λάθος
ή παλιά (μια δομή έκλεισε, άνοιξε μια πραγματική νέα δομή, ένας αριθμός δρόμου είναι λάθος),
στείλτε τη διόρθωση στην κεντρική εγκατάσταση. Θα έρθει στην επόμενη έκδοση του πακέτου
δεδομένων, για όλους.

## Σενάριο: τι θα γινόταν αν { #scenario-what-if }

Ένα σενάριο είναι μια υπόθεση: μια λίστα αλλαγών πάνω στα δεδομένα. Παραδείγματα: «ο δρόμος E02
είναι κλειστός», «η δομή F3 έχει ένα άτομο προσωπικό παραπάνω», «ένα νέο κοινοτικό κέντρο ανοίγει
στον κόμβο N-B2».

- Ένα σενάριο δεν αντιγράφει και δεν αλλάζει ποτέ τα δεδομένα· περιγράφει μόνο αλλαγές σε σχέση
  με αυτά.
- **Δημιουργείται με μία έκδοση δεδομένων** (φαίνεται στη σελίδα του σεναρίου) και ελέγχεται με
  αυτήν: κάθε δομή, δρόμος και μονάδα που αναφέρει πρέπει να υπάρχει.
- Έχει **κάτοχο** και **ορατότητα**. **Ιδιωτικό**: το βλέπουν ο κάτοχός του και οι διαχειριστές
  (οι διαχειριστές λειτουργούν την εγκατάσταση του δήμου και βλέπουν τα πάντα). **Κοινόχρηστο**: το βλέπουν
  όλοι οι χρήστες, και οι θεατές.
- Κάθε αποθήκευση δημιουργεί νέα **έκδοση** του σεναρίου. Οι προηγούμενες εκδόσεις μένουν, ώστε
  οι εκτελέσεις να λένε πάντα με ακρίβεια ποια έκδοση χρησιμοποίησαν.
- Κάποιες αλλαγές **καταγράφονται μόνο** προς το παρόν (αλλαγές στους χρόνους διαδρομής, νέοι
  δρόμοι, αλλαγές πληθυσμού): αποθηκεύονται και εμφανίζονται, αλλά δεν επηρεάζουν ακόμη τα
  αποτελέσματα.

## Εκτέλεση: η απάντηση, αμετάβλητη { #run-the-answer-kept-unchanged }

Μια εκτέλεση είναι ένας υπολογισμός μίας έκδοσης σεναρίου με μία έκδοση δεδομένων.

- Καταγράφει ό,τι χρειάζεται για να επαναληφθεί: σενάριο και έκδοση, πακέτο δεδομένων και έκδοση,
  έκδοση κώδικα, μοντέλο και έκδοση, σπόρο τυχαιότητας και ρυθμίσεις.
- **Δεν αλλάζει ποτέ** αφού τελειώσει. Νέα απάντηση σημαίνει πάντα νέα εκτέλεση.
- Αν εκτελέσετε ξανά την ίδια έκδοση σεναρίου με τα ίδια δεδομένα και τις ίδιες ρυθμίσεις, δεν
  γίνεται νέος υπολογισμός: ανοίγει η υπάρχουσα εκτέλεση.
- Τα αποτελέσματα έχουν πάντα την αβεβαιότητά τους: μια κεντρική τιμή (τη διάμεσο) και ένα
  διάστημα.
- Μέχρι να προστεθούν τα ερευνητικά μοντέλα, τα αποτελέσματα προέρχονται από ένα **διαγνωστικό
  μοντέλο**, που ελέγχει μόνο ότι η πλατφόρμα λειτουργεί. Δεν είναι ερευνητικά αποτελέσματα, και
  κάθε σελίδα το γράφει.

## Όταν ενημερώνονται τα δεδομένα { #when-the-data-is-updated }

Όταν ένας διαχειριστής εισάγει νέα έκδοση δεδομένων ή ενεργοποιεί ξανά μια παλαιότερη:

1. Μια **εκτέλεση βάσης** (χωρίς αλλαγές) μπαίνει στην ουρά με τα νέα δεδομένα.
2. Κάθε σενάριο **ελέγχεται ξανά** με τα νέα δεδομένα. Ένα σενάριο που αναφέρει κάτι που δεν
   υπάρχει πια (για παράδειγμα μια δομή που έκλεισε) δείχνει **Χρειάζεται έλεγχο με τα τρέχοντα
   δεδομένα** (Needs attention) και δεν μπορεί να εκτελεστεί μέχρι να διορθωθεί.
3. Οι υπάρχουσες εκτελέσεις μένουν όπως ήταν: δείχνουν τα δεδομένα που χρησιμοποίησαν. Η σελίδα
   της εκτέλεσης γράφει «Η εκτέλεση χρησιμοποίησε δεδομένα 1.0.0· τα ενεργά δεδομένα είναι
   1.1.0.» και προσφέρει **Νέα εκτέλεση με δεδομένα 1.1.0** (Rerun on data 1.1.0).
4. Στη σελίδα του σεναρίου, το «Δημιουργήθηκε με τα δεδομένα 1.0.0· ενεργά είναι τα δεδομένα
   1.1.0.» σας θυμίζει ότι μια νέα εκτέλεση χρησιμοποιεί τα ενεργά δεδομένα.
5. Στη λίστα **Σενάρια** (Scenarios), ένα σενάριο χωρίς εκτέλεση με τα ενεργά δεδομένα δείχνει
   **Τελευταία εκτέλεση στα δεδομένα 1.0.0** (Latest run on data 1.0.0), και ένα σενάριο που δεν
   εκτελέστηκε ποτέ δείχνει **Δεν έχει εκτελεστεί ακόμη** (Not run yet).

## Ποιος κάνει τι { #who-does-what }

| Ρόλος | Μπορεί να |
| --- | --- |
| **Θεατής** | Βλέπει τα κοινόχρηστα σενάρια και τις εκτελέσεις τους: αποτελέσματα, χάρτη, πίνακα, εξαγωγές. Δεν μπορεί να δημιουργήσει, να αλλάξει ή να εκτελέσει σενάρια· για να δει αποτελέσματα ενός σεναρίου που δεν εκτελέστηκε ποτέ, ζητά από έναν αναλυτή να το εκτελέσει. |
| **Αναλυτής** | Ό,τι και ο θεατής, και επιπλέον να δημιουργεί, να αλλάζει, να εκτελεί, να αντιγράφει και να μοιράζεται τα δικά του σενάρια, και να εκτελεί τη βάση. |
| **Διαχειριστής** | Ό,τι και ο αναλυτής, σε κάθε σενάριο (και στα ιδιωτικά σενάρια άλλων χρηστών), και επιπλέον να διαχειρίζεται χρήστες, να εισάγει πακέτα δεδομένων και να επιλέγει την ενεργή έκδοση δεδομένων. |
| **Κεντρική εγκατάσταση** (hub, εκτός της εγκατάστασης του δήμου σας) | Φτιάχνει και δημοσιεύει πακέτα δεδομένων· δέχεται διορθώσεις στα δεδομένα. |
