# 0018. Documentation site: MkDocs Material, mike, Mermaid

- Status: Accepted for v0.1, to be revisited
- Date: 2026-11-25
- Related: AGENTS.md "Diagrams", "Maintaining these instructions"; `mkdocs.yml`, `tools/docs/`, `.github/workflows/docs.yml`

## Context

The documentation lives in Markdown under `docs/` and at the repository root, and must read well on GitHub. Users (municipal staff), testers, researchers and developers need one navigable site with search, the user guide per platform version, and diagrams that change with the code. Files must not move, because code, tests and `AGENTS.md` link to their paths. Generated content (indexes, dependency lists) must not be maintained by hand.

## Options

1. **MkDocs + Material for MkDocs + mike** (BSD-2-Clause, MIT, BSD-3-Clause): Markdown as is, Mermaid through `pymdownx.superfences`, built-in search, versions on GitHub Pages with a selector. Material announces end of life on 2027-05-05 (critical fixes until then); its successor Zensical reads `mkdocs.yml`.
2. **Zensical**: the successor, younger; versioning support and plugin equivalents to be checked.
3. **Sphinx + MyST** (BSD, MIT): powerful, but heavier configuration and a different Markdown dialect for admonitions and cross-references.
4. **GitHub rendering only**: no search, no versions, no navigation for non-developers.

## Decision

MkDocs with the Material theme, versioned with mike and published to GitHub Pages from a workflow; all diagrams are Mermaid code blocks. A small hook (`tools/docs/hooks.py`) adds `CHANGELOG.md`, `CONTRIBUTING.md` and `AGENTS.md` to the site without copying them and rewrites links that leave `docs/` to GitHub. The tooling is a locked uv environment in `tools/docs/` and is licence-checked like the rest.

## Consequences

- `make docs`, `make docs-build` (`--strict`, run in CI with link checking by lychee).
- Indexes (ADRs, specs, open-question counts) and the dependency report are generated by scripts and checked in CI.
- Revisit before 2027-05: migrate to Zensical (or another maintained option) once it supports versioned sites; `mkdocs.yml` and the Markdown should carry over.
